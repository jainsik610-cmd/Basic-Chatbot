# Basic Chatbot Using Python

## Project Description
This project is a simple Python-based chatbot developed as part of my CodeAlpha internship. It interacts with users through text-based conversations and provides predefined responses.

## Features
- Interactive text-based conversation
- Predefined responses
- Basic conversational logic
- User-friendly interface
- Simple Python implementation

## Technologies Used
- Python
- VS Code

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python chatbot.py
```
